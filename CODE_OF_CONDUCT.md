# Code of conduct

This project is used for learning the Quran. Keep every discussion respectful, patient and on topic.

- Be kind to beginners, teachers and translators. Assume good faith.
- No harassment, insults, discrimination or personal attacks, in issues, pull requests, reviews or elsewhere in the project.
- Disagreement about religious interpretation is not for this tracker. We only discuss how the app works and whether text is displayed exactly as in the source.
- No spam, advertising or unrelated promotion.

Maintainers may edit or remove comments, close issues and pull requests, and block people who break these rules. Report a problem to halo@sambungayat.com; reports are kept private.

This is a short code written for this project, in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
